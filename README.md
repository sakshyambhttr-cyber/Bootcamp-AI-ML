# Bootcamp AI-ML Assignments Repository

This repository contains completed coursework and assignments for the AI-ML Bootcamp:

- **stroke_predict.ipynb**: Stroke prediction ML project featuring exploratory data analysis (EDA), preprocessing pipelines (`SimpleImputer`, `StandardScaler`, `OneHotEncoder`), and classification models (Logistic Regression, Decision Tree, Random Forest) with class imbalance handling.
- **visualization_assignment.ipynb**: Exploratory Data Analysis & Visualization for IPL 2022 dataset using Matplotlib and Seaborn.
- **panda_assignment.ipynb**: Pandas application and feature extraction on the anime dataset (`anime.csv`).
- **numpy_assignment.ipynb**: NumPy array creation, indexing, slicing, broadcasting, vector arithmetic, and universal functions.
